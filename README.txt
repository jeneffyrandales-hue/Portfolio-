JENEFFYR'S LITTLE CORNER OF THE INTERNET
HTML5 + CSS + JavaScript Portfolio

FILES
- index.html: all website content and page structure
- style.css: colors, typography, responsive layout and styling
- script.js: mobile menu, memory filters, question buttons, and current year

HOW TO UPLOAD TO GITHUB USING ANDROID
1. Open your GitHub repository in Chrome.
2. Tap Add file, then Upload files.
3. Upload index.html, style.css, and script.js. You can also upload this README.
4. Scroll down and tap Commit changes.
5. Open the repository Settings.
6. Open Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Choose branch main and folder /(root), then Save.
9. Wait a few minutes and refresh the Pages settings to find your published website link.

IMPORTANT
- Keep index.html, style.css, and script.js together in the same repository folder.
- The site uses online Google Fonts and sample scenic photos, so those parts require an internet connection.
- The memory cards are placeholders. To add a personal photo, upload the photo to your repository (for example, photos/friends.jpg), then replace the placeholder block in index.html with:
  <img src="photos/friends.jpg" alt="A memory with friends">
  Add CSS to size the image as desired.
- The profile photo is a placeholder. Replace it with your own photo if you wish.
- The phone contact currently has no number because no number was supplied. Add your phone number to the tel link in index.html if you want it clickable.
- Social links currently point to the general Facebook and Instagram websites. If you want exact profile links, replace the href values with your profile URLs.
- The poetry section contains a sample short poem. Replace it with your own original writing if you want.
- This is a static website. The question buttons are locally scripted and are not connected to an AI service or database.
- If you want a true copy of all original private photos and the original Lovable source code, download/export those assets from your Lovable project and add them yourself.
