JENEFFYR'S LITTLE CORNER — HTML5 / CSS / JAVASCRIPT

FILES
- index.html: page content and semantic HTML5 structure
- style.css: colors, layout, responsive styles, and animations
- script.js: mobile navigation, current year, and scroll reveal effects

HOW TO PREVIEW ON ANDROID
1. Extract the ZIP file using your phone's Files app.
2. Open the extracted folder.
3. Tap index.html. If it does not open correctly, open it with Chrome or another browser.
4. For a reliable hosted version, upload index.html, style.css, and script.js to the root of a GitHub repository and enable GitHub Pages.

PERSONALIZE BEFORE PUBLISHING
1. In index.html, replace your-email@example.com with your real email address.
2. The About section includes a photo placeholder. To use your own photo, place an image file in this folder and replace the .photo-placeholder element in index.html with:
   <img src="your-photo.jpg" alt="Jeneffyr Andales" class="profile-photo">
   Then add this to style.css:
   .profile-photo { display:block; width:100%; min-height:350px; height:100%; object-fit:cover; }
3. Update project descriptions to match your final submitted work.
4. Update social links or add them if you want to include your social accounts.

NOTES
- This is a static website and does not require a server to preview.
- The Google Fonts link needs an internet connection; fallback fonts are included.
- The contact button opens the visitor's email app. It does not send messages to a database.
- The live Lovable URL could not be inspected reliably during creation, so this version is based on the portfolio details available in the conversation. Compare it with your live page and adjust any differences.
